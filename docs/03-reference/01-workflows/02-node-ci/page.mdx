# Node CI workflow

Use `reusable_node-ci.yml` for configurable Node workspace checks. It is intended for consuming repositories that need a combined CI job. When separate `ci_*` workflows already own Vitest, linting, typechecking, or npm packaging, disable the matching checks to avoid duplicate runs.

## Full CI caller

```yaml
jobs:
  ci:
    uses: moyarich/reusable-workflows/.github/workflows/reusable_node-ci.yml@v0
    with:
      node-version: "24"
```

Defaults preserve existing behavior: install dependencies, build local workspace dependencies, test, lint, typecheck, and validate workspace package tarballs.

## Build-only caller alongside separate checks

```yaml
jobs:
  build:
    uses: moyarich/reusable-workflows/.github/workflows/reusable_node-ci.yml@v0
    with:
      package-directory: all
      run-tests: false
      run-lint: false
      run-typecheck: false
      run-pack: false
```

When a dedicated `ci_*` workflow already builds the same packages, omit this reusable Node CI job instead of running another build-only job.

## Inputs

| Input | Default | Purpose |
| --- | --- | --- |
| `checkout-ref` | `""` | Optional checkout override for workflow callers |
| `package-directory` | `.` | Root, workspace path/name, or `all` |
| `packages-directory` | `packages` | Directory scanned for the `all` selector |
| `node-version` | `24` | Node.js version |
| `browser-tests` | `false` | Install Chromium for browser-oriented test scripts |
| `run-tests` | `true` | Run npm workspace tests |
| `run-lint` | `true` | Run ESLint directly if configured |
| `run-typecheck` | `true` | Run workspace TypeScript typechecking |
| `run-pack` | `true` | Inspect npm package tarball with `npm pack --dry-run` |

The `run-*` options are also available in manual workflow dispatch. The workspace must have a committed npm lockfile for `npm ci`.

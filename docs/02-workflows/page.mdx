# Reusable Workflows

Every public workflow lives directly in `.github/workflows/` and uses the `reusable_` prefix.

## CI and quality

- `reusable_node-ci.yml` — Node.js install, build, and test orchestration.
- `reusable_check-dist.yml` — rebuild committed distribution output, fail when it differs, and upload the rebuilt output for inspection.
- `reusable_package-ci.yml` — package discovery plus per-package Node CI.
- `reusable_prettier.yml` — Prettier formatting with optional self-healing commits.
- `reusable_discover-packages.yml` — workspace package discovery using `@moyarich/workspace-tools`.

## Releases

- `reusable_release-drafter.yml` — create or update GitHub Release drafts. This is draft preparation only; it does not replace the npm release workflow.
- `reusable_release.yml` — create or update GitHub Releases from resolved release metadata.
- `reusable_publish-action.yml` — promote a published stable release tag such as `v1.2.3` to its moving major compatibility alias such as `v1`.

## npm release and publishing

- `reusable_npm-package-lock.yml` — npm lockfile validation and optional self-healing commits.
- `reusable_npm-prepare-release.yml` — prepare package versions and release state.
- `reusable_npm-release.yml` — perform the npm package release lifecycle for existing and new callers.
- `reusable_npm-publish.yml` — publish prepared npm packages.
- `reusable_codemod-publish.yml` — publish Codemod Registry packages.

## VS Code extensions

- `reusable_vscode-extension-publish.yml` — validate, package, publish to the VS Code Marketplace, and promote the matching GitHub draft release.

## Documentation and repository automation

- `reusable_github-pages.yml` — build and deploy GitHub Pages sites.
- `reusable_readme-screenshots.yml` — regenerate README screenshots.
- `reusable_manage-issue-dependencies.yml` — manage issue dependency relationships.
- `reusable_show-issue-dependency-tree.yml` — render issue dependency trees.

## Calling a workflow

```yaml
jobs:
  publish:
    uses: moyarich/reusable-workflows/.github/workflows/reusable_vscode-extension-publish.yml@v0.1.0
    with:
      target-branch: main
      dry-run: true
    secrets:
      vsce-pat: ${{ secrets.VSCE_PAT }}
```

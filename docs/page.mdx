# Reusable Workflows

Reusable Workflows is the shared automation repository for Node.js projects, npm packages, VS Code extensions, documentation sites, and other Moya repositories.

## Public automation surface

| Type                 | Location                                                 | Contract                    |
| -------------------- | -------------------------------------------------------- | --------------------------- |
| Reusable workflows   | `.github/workflows/reusable_*.yml`                       | Public                      |
| Reusable actions     | `actions/*/action.yml`                                   | Public                      |
| Scripts and tooling  | `scripts/*`                                              | Documented reusable tooling |
| Repository workflows | `.github/workflows/*.yml` without the `reusable_` prefix | Internal                    |

Start with [Getting started](./01-getting-started/page.mdx), browse the [workflow catalog](./02-workflows/page.mdx), or see [Development](./04-development/page.mdx) for repository structure and maintainer guidance.

## Release and versioning

This repository distributes reusable GitHub Actions workflows and standalone actions, **not an npm package**. Its releases use immutable `vX.Y.Z` tags (the next planned release is `v0.2.1`) and a moving `v0` major-compatible alias.

Callers can pin a published version with `@v0.2.1` after release or use `@v0` to follow compatible updates. Use `@main` only to test unreleased changes.

The separately maintained `@moyarich/workspace-tools` npm package provides CLIs consumed by some workflows. Its npm versions are independent of the reusable-workflows GitHub release version.

See [Getting started](./01-getting-started/page.mdx) and [Repository release](./04-development/03-repository-release/page.mdx) for the release process.

## Copyable examples

Consumer-ready workflow callers live under `examples/`. Each example is a first-class repository example, such as:

```text
examples/
├── github-pages/
│   └── workflow.yml
├── node-ci/
│   └── workflow.yml
└── ...
```

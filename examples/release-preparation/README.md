# Release preparation plan example

The example [release-preparation.example.json](./release-preparation.example.json) shows the tracked release selection file generated by `reusable_prepare-release-pr.yml`.

When opening a preparation PR, the workflow writes **`.github/release-preparation.json`** on its new `release/prepare-*` branch, using the same structure:

```json
{
  "schemaVersion": 1,
  "packages": [
    { "name": "@example/core", "directory": "packages/core" },
    { "name": "@example/cli", "directory": "packages/cli" }
  ]
}
```

The file records package **identity and directory**, not fixed versions or a commit SHA. The PR branch is editable: code, tests, changelogs and `package.json` versions may change during review. On merge, the release workflow uses the package selection from the merged file and reads the **final versions from the merged package manifests** before creating the tag and GitHub Release.

This example belongs in `examples/` only; do not copy it into `.github/release-preparation.json` in `main` as an active release plan. Publication is independent and is never triggered by merging a preparation PR.

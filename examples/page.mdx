# Examples

These examples are repository-owned caller workflows. The MDX pages provide the browsable documentation surface while each `workflow.yml` remains the authoritative copyable caller.

Copyable examples use the moving `@v0` major alias so callers receive compatible 0.x workflow updates. Pin an immutable `v0.x.y` tag when exact reproducibility is required.
